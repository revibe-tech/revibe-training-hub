## Summary

This training walks a new KAM through the Revibe seller ecosystem using an 11-page deck. Its stated purpose is to present the whole Revibe ecosystem in which sellers and KAMs evolve to run supply operations [00:04 t00000] [00:11 t00000]. It is for key account managers who need to explain the seller journey to sellers [06:47].
