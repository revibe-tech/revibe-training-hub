- ★ The Fulfillment App is a frontend with some features. The data it shows is stored in the backend, the Google Sheet "Fulfillment App - O&D" [00:09][00:16][00:00 t00000].
- ★ Usually you are not supposed to input any data in the backend tabs or in the Fulfillment app, according to the trainer [02:57].
