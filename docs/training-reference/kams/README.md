# Revibe KAM Training Reference

This is the front page of the training reference for key account managers (KAMs) at Revibe. It covers the Revibe seller ecosystem and the tools sellers and KAMs use: onboarding, Fulfillment, Buybox, Orders, cancellations, returns, refunds, warranties, the seller agreement, quality guidelines, dashboards, South Africa bulk shipments and commitments.

## Who this is for

- **KAMs** who need to explain the seller journey and the tools to sellers, and who need to check a rule before they give an answer.
- **Trainers and team leads** who write quizzes or onboarding material from the source videos and PDFs.
- **Anyone maintaining the material** when Revibe changes a screen, a rule or a policy.

Each item page is the detailed, cited record of one source video or PDF. Each topic page groups related items and gives the quiz blueprint, the contradictions and the open questions. Start with the topic page for the area you need, then open the item page to check the exact citation.

## How this reference was made

1. **Speech recognition.** Every video was transcribed with faster-whisper (large-v3-turbo for most items, medium for others). Words the model was unsure of are marked as low confidence. The catalog lists the count for each item.
2. **Frames.** Frames were taken whenever the screen changed, not at fixed intervals. The Frames column is the number of frames kept for each item. PDFs were read page by page.
3. **Packs.** Each item was split into parts (packs) of up to about 40 frames and transcript segments. One agent wrote the facts for each part, following the trainer's narration and the on-screen content.
4. **Adversarial check.** A separate checker went through each part and tried to disprove each claim against the transcript and frames. Failed claims were removed or corrected, and missing facts were added.
5. **Critic.** An independent reviewer read each finished page and listed issues. High-severity issues were fixed before release.
6. **Final audit.** Two auditors checked the set of pages for consistency across items and topics.

The run stats below show, for each item, how many facts were drafted, how many claims were checked, and how many were removed, corrected or added.

### Limits

- **Speech recognition errors.** The transcripts contain errors, especially where a speaker has a French accent. Low-confidence words are marked on the item pages. Where a name, number or term was corrected, the page says so. Do not quote a transcript word as fact when it is marked low confidence.
- **Sampled frames.** Frames are sampled on screen changes. A value that appears on screen only briefly, or that was cut off, may be missing or misread. Some item pages flag these gaps.
- **Nothing beyond the material.** The reference contains only what the videos, PDFs and their frames show or say. It does not record current policy, live numbers or anything that happened after the recordings. Many items carry snapshot figures and dates. Treat these as examples from the recording, not as current facts.
- **Dates and status.** Several items are marked as possibly out of date, and item 4.0 is flagged TBU (to be updated). Check the live app or the current policy before you teach or quote a rule.
- **Personal data.** Some screens show customer details, staff emails or seller names. Do not show these pages to sellers without redaction.

## How to use this reference

### Writing quizzes

1. Choose the topic page. Each topic has a **Quiz blueprint** with a suggested question count (about one per minute of video, capped at 20), the areas to cover, which areas suit multiple-answer questions, and scenario seeds with citations.
2. Use only the confirmed rules. Each blueprint names the points to avoid because the source is unclear, out of date or contradicted. Respect those lists.
3. Check each stem and answer against the item page. Every fact has a citation in the form (item id and video time), for example (3.0 [05:41]). PDF pages are cited as (8.1 p2).
4. Do not write a question from a row marked low confidence, from a snapshot figure, or from a figure in the Contradictions section unless the question tests that the point is unsettled.
5. Ask for a quiz on the seller version when the audience is sellers, and on the KAM version when the audience is KAMs. Where a topic has both (for example 1.0 and 1.1, or 3.0 and 3.1), the two versions differ in depth, so say which one a question is based on.
6. Redact any personal data that appears in a screenshot or in a sample record before a quiz uses it.

### Updating the material

1. Find the item in the catalog and open its item page. Check the Contradictions and Problems sections first, since they list what the source did not settle.
2. When a screen, rule or policy changes, correct the item page first. Keep the citation, and mark the change with the date it was checked.
3. Then update the topic page. The rules table, the contradictions and the quiz blueprint may all need changing. Remove a contradiction only when the new source settles it.
4. Do not add a fact that has no citation to the item page. If the source material cannot show the change, record it as an open question instead.
5. For a new or replaced video, add a row to the catalog with its id, length, frames and low-confidence count, add its item page, and put it in the matching topic page. Leave the run stats below as the record of the earlier run, and add a note with the new run.
6. Do not show items marked as seller-facing and KAM-only to the wrong audience. Items 11.0, 2.1, 2.2, 3.0 and 1.0 contain staff or internal information.
